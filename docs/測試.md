# 測試

## 測試環境

- 引擎: Godot 4.7.2
- 框架: GUT
- 程式語言: GDScript
- CI: GitHub Actions

或是請參考 [GUT Install](https://gut.readthedocs.io/en/v9.6.0/Install.html) 與[Quick Start](https://gut.readthedocs.io/en/v9.6.0/Quick-Start.html) 自行在開發本地安裝。

## 執行方式

### Terminal

```bash
cd game

godot --headless --path . \
    -s addons/gut/gut_cmdln.gd \
    -gdir=res://tests/unit \
    -gexit
```

### Godot UI

請參考 [Quick Start](https://gut.readthedocs.io/en/v9.6.0/Quick-Start.html)。

### Github Actions

在開啟 PR 的情況下，可以前往 [Actions](https://github.com/emmetthor/Our_Games_1.0/actions) 查看最近的測試結果。

## 測試規範

1. 測試檔案命名為 `test_*.gd`。
2. 測試函式命名為 `test_*()`。
3. 每個測試應能獨立執行。
4. 不應依賴其他測試的執行順序。
5. 修正 Bug 時，優先新增能重現 Bug 的測試。
6. 修改核心邏輯後，必須確認相關測試通過。
