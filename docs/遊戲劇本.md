# 遊戲劇本

## 文字顯示與演出標記

本稿保留劇情流程與演出說明。實際顯示在遊戲畫面上的文字，依下列標記區分；標記本身不顯示。

- **對話**：`[對話-對象]` 標示一段對話；其下每一條角色台詞各為一則對話框，同一角色連續發話時依序顯示。
- **獨白與字幕**：`[獨白]`、`[字幕]` 為顯示文字；連續多條字幕依序呈現，不合併成一整屏。字幕外層的「」用來界定引文，不必重複顯示。
- **任務與操作提示**：`[提示-指定範圍]`、`[提示-不指定範圍]`、`[提示-執行動作]` 為玩家可見的目標或指引。連續操作提示依任務進度更新。
- **系統與選項**：`[系統]` 為狀態、教學收錄或獎勵通知；`[選項]` 其下各條文字為可選項目。連續系統通知可分則顯示。
- **演出說明**：`[動畫]`、`[畫面]`、`[動作]`、`[音樂]` 描述鏡頭、場景、角色行為與聲音，不作為整段文字直接顯示。場景內明確寫出的招牌、介面文字與文件內容仍須呈現。
- **流程與製作備註**：`[觸發條件]`、`[備註]`、章節下的引用區塊，以及對話標題括號內的條件只供製作使用，不顯示給玩家。
- **事件標記**：`[建造]`、`[拆除]`、`[擊敗]` 用來標示事件完成，並非台詞。
- **特殊字元、符號**：保留場景代碼、指令、編碼格式與專有名稱；反引號只作為稿件標記，不顯示在介面上。
